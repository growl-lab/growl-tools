# growl-tools

Python tools for the [GROWL catalog](https://github.com/growl-lab/growl-catalog): converting population-synthesis output to the GROWL standard HDF5 format, computing formation efficiencies, and cosmic integration.

## Install

    pip install git+https://github.com/growl-lab/growl-tools.git

For development:

    git clone https://github.com/growl-lab/growl-tools.git
    cd growl-tools
    pip install -e ".[test]"
    pytest
